# Simulado de Sistemas Operacionais — Etapa 2

Quiz web estático, responsivo, com 20 questões inéditas de múltipla escolha (cinco alternativas), explicação prévia, correção imediata, percentual de acertos e recuperação das questões incorretas.

## Como abrir

Abra `index.html` em um navegador. Não precisa instalar dependências nem iniciar servidor.

## Publicar com GitHub Pages

1. Acesse **Settings → Pages** neste repositório.
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha a branch **main** e a pasta **/(root)**; clique em **Save**.
4. Quando o deploy concluir, o endereço será `https://karlouchoa.github.io/quiz-sistemas-operacionais/`.

A URL só funcionará quando o GitHub Pages estiver ativado.

## Conteúdo e limites

Criado a partir das dicas do professor compartilhadas pelo estudante, abrangendo Bash read e testes de strings, i-node, segmentação e paginação, page fault e thrashing, remoção Linux, chamadas de sistema C/Unix, semáforos, VFS e chmod/xcopy. Foram acrescentados aprofundamentos gerais pontuais, como links físicos, sem afirmar que constavam nas dicas. O enunciado da questão 8 da lista original não foi fornecido e não foi reproduzido.

O estilo é inspirado em enunciados acadêmicos com interpretação de cenários e análise de afirmativas. As questões são autorais, **não oficiais**, e o projeto não tem vínculo ou endosso da Estácio.

## Privacidade

As respostas ficam apenas na memória da aba. Não há backend ou coleta de dados.
